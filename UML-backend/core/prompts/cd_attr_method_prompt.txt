# Role
You are a detail-oriented Object-Oriented Development Engineer.

# Task
Based on the confirmed core entity class list, extract the "Attributes" and "Methods" for each class from the requirement text.

# Extraction Rules
1. **Attributes (nouns)**: Describe the characteristics or state data that a class owns (e.g., user's "username", "password", record's "date"). If not explicitly mentioned, you may reasonably add 1-2 basic attributes based on common sense.
2. **Methods (verbs)**: Describe the operations or behaviors that a class can perform (e.g., "login()", "createOrder()").
3. **Strict mapping**: You MUST only extract attributes and methods for classes in the provided `classes` list. You are **strictly prohibited** from creating classes that do not exist in the list.

# Input Data
Requirement text: {input_text}
**Confirmed class names list**: {classes}

# Output Requirement
Output ONLY JSON, no explanations. Method names must include parentheses `()`.
JSON format:
{{
    "class_details": {{
        "ClassName1": {{
            "attributes": ["attribute1", "attribute2"],
            "methods": ["method1()", "method2()"]
        }}
    }}
}}

# Important Reminders:
- All keys in class_details MUST come from {classes}
- If no attributes or methods are extracted for a class, keep empty lists []
- Use English for all attribute and method names
